Cómo trabajar
Clona el repo: git clone <url-del-repo>
Crea tu rama desde develop: git checkout develop → git checkout -b feature/tu-tarea
Trabaja, haz commits, y sube tu rama: git push origin feature/tu-tarea
Abre un Pull Request hacia develop para que alguien lo revise antes de unirlo

Instrucciones para instalar cada parte: ver backend/README.md y frontend/README.md.
