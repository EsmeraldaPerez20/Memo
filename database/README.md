# PostgreSQL - MEMO

## Configuración de la base de datos

- Motor: PostgreSQL
- Base de datos: memo_db
- Usuario: postgres
- Host: localhost
- Puerto: 5432

## Tablas principales

El proyecto utiliza PostgreSQL como sistema gestor de base de datos para las tablas de la aplicación MEMO.

La configuración de credenciales debe mantenerse fuera del repositorio.
